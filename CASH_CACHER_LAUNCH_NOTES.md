# Cash Cacher launch build

Brand: Cash Cacher
Tagline: Find the cash. Know the catch.
Editorial promise: We don't just show the bonus. We show the catch.

## Before production
1. Set the final custom domain in GitHub Pages and enforce HTTPS.
2. Add approved affiliate/referral URLs only after program approval and confirm promotional rules.
3. Re-verify time-sensitive offer terms before public launch.
4. Add real 192x192 and 512x512 icons to the PWA manifest.
5. Add analytics/Search Console after the production domain is live.
6. Replace placeholder legal pages with counsel-reviewed policies if the business expands or begins collecting personal data.

## Monetization fields
Each offer supports affiliate_url, affiliate_program_url, referral_program_url, monetization_type, partner_status, sponsored, cash_value, cash_score, score_basis, risk_protection and editorial_warning.


## Launch v2 offer expansion — September 25, 2026

- Expanded database from 132 to **525 offers**.
- Preserved all existing finance, app, sports, collectibles and Mystery Pack records.
- Added 393 current retailer cash-back discovery listings sourced from BeFrugal's supported-store directory.
- Dynamic cash-back listings deliberately do **not** hard-code a percentage when the rate is not individually verified; users are sent to the live source.
- Cash Scores are editorial, not user reviews. Dynamic cashback listings use deterministic varied scores based on accessibility/effort with a penalty for unknown live reward value and retailer-specific exclusions.
- Added visible score-basis text to each offer card.
- No affiliate URL is fabricated: new discovery listings remain unmonetized until Cash Cacher has an approved tracking relationship.
